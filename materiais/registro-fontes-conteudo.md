# Registro de fontes de conteúdo — modelo operacional

Este arquivo é um modelo de controle. Não contém credenciais, dados pessoais nem substitui a guarda institucional de documentos.

## Como usar

1. Criar uma linha para cada afirmação relevante, indicador, imagem, parceria ou documento usado em uma página.
2. Não preencher campos sem confirmação. Usar **[INFORMAÇÃO A SER VALIDADA PELO INSTITUTO]** quando a confirmação ainda não existir.
3. Revisar o registro antes de cada publicação e em toda atualização de transparência.

## Critério de encerramento da Sprint 0C

A Sprint 0C só pode ser marcada como concluída após o Instituto validar formalmente os cinco eixos, os responsáveis editoriais, a taxonomia de status, as fontes prioritárias e esta matriz de rotas.
